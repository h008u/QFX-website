# QFX — منصة وكيل فوركس (IB Platform)

منصة متكاملة لوكيل معرّف (Introducing Broker) تعمل بتكلفة **$0** على الخطط المجانية:

| الجزء | المسار | الاستضافة |
| --- | --- | --- |
| الموقع (Landing, الأسواق، التوصيات، المجتمع، لوحة التحكم) | `apps/web` — Next.js 15 + Tailwind | Vercel (Hobby) |
| بوت تيليجرام + API + المهام الآلية | `apps/bot` — grammY + Hono (Webhooks) | Render أو Koyeb (Free) |
| قاعدة البيانات + Auth + Realtime | `supabase/` | Supabase (Free) |
| أنواع ومنطق مشترك | `packages/shared` | — |

```text
[الزوار] → [Vercel: الموقع] ◄──Realtime── [Supabase: DB/Auth]
                │ (لوحة التحكم)                    ▲
                ▼                                   │ service_role
        [Render/Koyeb: البوت] ──────────────────────┘
          ▲            │
 Telegram/TradingView  ▼
   Webhooks     [قناة تيليجرام]
```

## التصميم

واجهة داكنة بأسلوب تطبيقات التداول الاحترافية:
- خلفية `#0A0A0A` وبطاقات `#121212` وحدود رفيعة `#27272A`.
- أخضر `#10B981` للصعود/الربح وأحمر `#FF3B30` للهبوط/الخسارة فقط.
- شريط تنقل سفلي زجاجي (Glassmorphism) على الجوال.
- خط أحادي المسافة (JetBrains Mono) لكل الأسعار والأرقام حتى لا تهتز عند التحديث.
- شارتات شموع بمكتبة **TradingView Lightweight Charts** المجانية (Apache-2.0) مع رسم مستويات التوصيات المفتوحة (الدخول / SL / TP) على الشارت.

### ثيمات الواجهة
خمسة ثيمات تُختار من **لوحة الإدارة ← الإعدادات ← مظهر الموقع** (للمدير فقط)، وتُطبّق على كل الصفحات فوراً:

| الثيم | الطابع | الوضع |
|---|---|---|
| **المؤسسي** (الافتراضي) | فاتح، كحلي وذهبي، خط Noto Kufi، شريط أسعار | فاتح + داكن |
| الكلاسيكي | أسلوب منصات الشارتات، أزرق وأزرار دائرية | فاتح + داكن |
| الطرفية الاحترافية | داكن كثيف، كهرماني، أرقام JetBrains Mono | داكن دائماً |
| النيون الزجاجي | طبقات زجاجية وإضاءات بنفسجية/زرقاء | داكن دائماً |
| الذهبي الفاخر | أسود وذهبي، El Messiri وCormorant | داكن دائماً |

- **معاينة دون تغيير الموقع للزوار:** أضف `?theme=neon` (أو أي ثيم) لأي رابط، و`?theme=reset` للإلغاء.
- الألوان معرّفة في `scripts/gen-themes.py` وتولّد `apps/web/app/themes.css` (`python3 scripts/gen-themes.py`).
- الثيم محفوظ في جدول `settings` بالمفتاح `site.appearance`، ويمكن فرض ثيم افتراضي عبر `NEXT_PUBLIC_SITE_THEME`.

### محتوى الموقع القابل للتعديل
- **التعديل المباشر:** من لوحة الإدارة ← محتوى الموقع ← «التعديل المباشر على الصفحة» (أو افتح `/?edit=1` وأنت مسجّل كمحرر/مدير): انقر أي نص لتعديله، اسحب الأقسام من المقبض لترتيبها (فأرة أو لمس)، أخفِ/أظهر أي قسم، ثم «حفظ ونشر».
- **لوحة «محتوى الموقع»:** ترتيب الأقسام بالسحب، كل النصوص، بطاقات «لماذا QFX»، خطوات الانضمام، الأسئلة الشائعة، وشريط إعلان أعلى الموقع.
- يُحفظ في `settings` بالمفتاح `site.content`؛ التعريفات والقيم الافتراضية في `apps/web/config/site-content.ts`.

## الميزات

**الموقع**
- `/` صفحة هبوط: شارت حي، شريط أسعار، إحصائيات الأداء، مميزات الوكالة، خطوات الانضمام، نموذج طلب انضمام.
- `/markets` قائمة مراقبة + شارت شموع (إطار الساعة) + خطوط التوصيات.
- `/signals` التوصيات الحية والسجل التاريخي، نسبة النجاح ومجموع النقاط — تحديث فوري عبر Realtime.
- `/feed` مغذى أخبار وتحليلات بأسلوب قنوات تيليجرام مع فلترة حسب الأصل (عملات، ذهب، نفط، مؤشرات، المفكرة).
- `/how-it-works` شرح الخطوات والأسئلة الشائعة.
- `/login` و `/account` تسجيل دخول الأعضاء برابط سحري على البريد (Supabase Auth بدون كلمة مرور)، تعديل الاسم ومعرّف تيليجرام، ورابط إحالة شخصي `?ref=CODE`.
- **النقاش**: تعليقات تحت كل خبر وتحليل وتوصية مفتوحة، تظهر للجميع فوراً (Realtime). الكتابة للأعضاء فقط، بحد 10 تعليقات في الدقيقة.
- **تتبّع الإحالة**: أي زيارة بـ `?ref=CODE` تُحفظ في كوكي 30 يوماً، وتُنسب لطلب الانضمام وللعضو الجديد عند تسجيله.
- `/admin` لوحة إدارة كاملة (انظر القسم التالي).
- بدون مفاتيح Supabase يعمل الموقع **ببيانات توضيحية** مع تنبيه واضح.

**البوت** (`apps/bot`)
- `POST /telegram/webhook` — أوامر المدير في تيليجرام:
  - `/signal BUY XAUUSD 2350 SL 2340 TP 2360 TP2 2370 ملاحظة` (يقبل `شراء/بيع` والأرقام العربية)
  - `/close <id> tp|sl|close|cancel [سعر الخروج]` — يرد على رسالة التوصية الأصلية ويحسب النقاط
  - `/news` و `/analysis` (السطر الأول عنوان)، `/id`، `/start`
- `POST /api/signals`، `PATCH /api/signals/:id`، `POST /api/news` — تستخدمها لوحة التحكم (`Authorization: Bearer BOT_API_KEY`).
- `POST /webhooks/tradingview?secret=...` — تنبيهات TradingView (JSON أو نص بصيغة `/signal`).
- `POST /api/jobs/tick` — دورة المهام الآلية (كل 5–10 دقائق من cron خارجي، وتوقظ الخدمة المجانية): نشر المجدول، جلب الأخبار، مزامنة المفكرة، أجندة اليوم، التنبيه قبل الخبر القوي، تنبيهات الأسعار، التحيات، ملخص الأسبوع والاستطلاع. محمية بقفل حتى لا تعمل دورتان سوا.
- `POST /api/posts/:id/publish` (نشر/موافقة/إعادة إرسال للأماكن الفاشلة)، `POST /api/test/:what` (تجربة فورية)، `GET /api/status`، `POST /api/destinations/check`، `GET /api/news/sources`.
- أوامر إضافية للمدير: `/pause` و `/resume` و `/status` و `/tick`، وأزرار ✅ نشر / ❌ تجاهل بالخاص لكل منشور ينتظر الموافقة.

## لوحة الإدارة `/admin`

مبنية على أفكار ومميزات [Spir-Telegrambot](https://github.com/inzohussein-blip/Spir-Telegrambot) ومنقول منها منطق التصنيف والتقييم وكشف المكرر والقوالب والتحيات وقراءة الأخبار.

**الدخول:** بحساب Supabase (رابط سحري على البريد من `/login`) ودوره: **مدير** (كل شيء) أو **محرر** (ينشر ويوافق ويعدّل المحتوى والإعدادات) أو **مشاهد** (يرى فقط). كل إجراء يُسجَّل باسم صاحبه. بدون Supabase تعمل اللوحة في **وضع المعاينة** ببيانات توضيحية.

| الصفحة | ما تفعله |
| --- | --- |
| نظرة عامة | منشورات اليوم والأسبوع، ما ينتظرك، الفاشل والمفلتر، رسم 7 أيام، المواعيد القادمة، آخر نشاط، وتحذيرات (مهمة متوقفة، نشر متوقف، لا أماكن نشر، لا نسخة احتياطية) |
| التدفق والسجل | مخطط المصادر ← الفلترة ← الموافقة ← أماكن النشر مع حالة كل مصدر وكل مكان، وسجل مباشر (Realtime) لكل عنصر وسببه، مع نشر الآن / انشره رغم ذلك / أعد الإرسال للتي فشلت |
| المراجعة والموافقة | تعديل النص مع معاينة بشكل تيليجرام ثم نشر أو تجاهل، وتبويب للمفلتر والمكرر |
| منشور جديد | قوالب جاهزة بخانات `{...}` (السطر الفارغ يُحذف)، تنسيق عريض/مائل/رابط، صورة من المكتبة، تحذير «ليس توصية مالية»، نشر الآن أو جدولة أو مسودة |
| تقويم المحتوى | شهر كامل: المجدول (اسحبه ليوم آخر أو غيّر وقته أو ألغه)، المواعيد الثابتة، والأخبار القوية؛ قائمة على الجوال |
| التوصيات والأداء | إرسال وتحديث التوصيات، منحنى النقاط، نسبة النجاح، معامل الربح، أكبر تراجع، النتائج الشهرية، أداء كل أداة |
| تنبيهات الأسعار | «إذا XAUUSD صعد فوق 2400» مرة واحدة أو متكرر مع فترة تهدئة، والبوت يراقب السعر بنفسه |
| غرفة الأخبار | كل الأخبار وحالتها مع فلتر المصدر، الأجندة الاقتصادية مع عد تنازلي وشرح القراءة المعتادة، وويدجتات TradingView الرسمية |
| العملاء والأعضاء | مراحل العميل حتى الإيداع، ملاحظات، الإحالات وأكثر من أحال، تصدير CSV |
| الإعدادات | أماكن النشر (قنوات/مجموعات/مواضيع ولكل مكان أنواعه مع فحص صلاحيات البوت)، المصادر (مع فحص من السيرفر ومصادر RSS إضافية)، الأنواع وأسواق التركيز، الأجندة، التحيات بالصور والنصوص، ملخص الأسبوع والاستطلاع، العطل، TradingView، التوقيع والإيقاف المؤقت، وأزرار «تجربة الآن» |
| القواعد والقوالب | سياسة النشر لكل نوع (تلقائي / بموافقتك / حسب الأهمية) مع توزيع التقييمات ومحاكاة النتيجة، الكلمات الممنوعة والمطلوبة والمراقبة، ساعات الهدوء، محرر القوالب |
| مكتبة الصور | رفع وحذف ونسخ الروابط (Supabase Storage) |
| صحة النظام | حالة الخدمة والـ Webhook وكل مهمة وآخر خطأ، وزر «شغّل المهام الآن» |
| سجل النشاط / الفريق / النسخ الاحتياطي | من فعل ماذا ومتى ومن أي عنوان؛ إدارة الأدوار؛ تنزيل واسترجاع نسخة JSON |

| بوتات التحليل | 9 استراتيجيات (تقاطع الاتجاه، ارتداد RSI، زخم MACD، اختراق البيفوت، البولنجر، إيشيموكو، نماذج الشموع، بيفوت فيبوناتشي، الارتداد مع الاتجاه) بعد إغلاق كل شمعة، مع فلاتر الجلسة والتأكيد والأخبار والحد اليومي، ومتابعة الهدفين والوقف، واختبار على التاريخ مع المنحنى ومعامل الربح، وصورة شارت لكل إشارة |
| ربط MT5 | إضافة `mt5/QFXBridge.mq5` ترسل صفقاتك: الفتح والتعديل والإغلاق تنزل كتوصيات وتحديثات مترابطة، مع حالة الحساب والصفقات المفتوحة |
| تعليقات المجتمع | مراجعة وحذف تعليقات الأعضاء |

بالإضافة إلى: بحث سريع `Ctrl+K`، جرس إشعارات مع **إشعارات للجوال/الكمبيوتر** (Web Push مجاني)، **التحقق بخطوتين** بتطبيق مصادقة، **الوضع الفاتح** افتراضياً مع زر للداكن، **نسخة مترجمة** لكل مكان نشر (إنكليزي، كردي، تركي، فارسي...)، **عدد المشاهدات** لكل منشور، **نظرة الأسبوع** يوم الأحد، و**نتيجة الخبر بعد صدوره** (إذا أعطى المصدر الرقم الفعلي)، وأمر `/chart XAUUSD 1h` في تيليجرام لصورة شارت.

**ما لم يُنقل من Spir ولماذا:** إدارة عدة بوتات من لوحة واحدة (هذا المشروع وكالة واحدة ببوت واحد). صور الشارت هنا تُرسم بدون متصفح (SVG ← PNG) لتعمل على الخطة المجانية، والتحقق بخطوتين بتطبيق مصادقة (Supabase MFA) بدل رمز تيليجرام.

**إعدادات إضافية:**
- إشعارات الجهاز: ولّد مفاتيح مرة واحدة `npx web-push generate-vapid-keys` وضعها في البوت (`VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY`) والموقع (`NEXT_PUBLIC_VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY`)، ثم من الجرس «فعّل الإشعارات على هذا الجهاز».
- التحقق بخطوتين: فعّله من «حسابي»، و`ADMIN_REQUIRE_MFA=true` يجعله إلزامياً لكل الفريق.
- MT5: ضع نفس `MT5_SECRET` في البوت والموقع، ثم اتبع خطوات صفحة «ربط MT5».
- بوتات التحليل وتنبيهات الأسعار تحتاج `TWELVEDATA_API_KEY` (800 طلب/يوم مجاناً): كل رمز وإطار يستهلك طلباً عند إغلاق كل شمعة، فابدأ برمزين.

**قاعدة البيانات** (`supabase/migrations`)
- الجداول: `profiles` (المستخدمون وأدوار الفريق)، `signals`، `news`، `comments`، `leads`، `posts` (كل منشور وحالته — سجل التدفق والموافقة والجدولة)، `settings` (إعدادات البوت)، `price_alerts`، `audit_log`، `task_runs`، وعرض `signal_stats`.
- RLS مفعّل: قراءة عامة للتوصيات والأخبار والتعليقات، الكتابة للمدير فقط، الزوار يستطيعون إرسال طلب انضمام فقط، والعضو لا يستطيع تغيير دوره أو التعليق باسم غيره.
- اختبارات RLS حقيقية على PostgreSQL في `supabase/tests` (تعمل في CI):
  ```bash
  DATABASE_URL=postgres://postgres:postgres@localhost:5432/postgres supabase/tests/run.sh
  ```
- Realtime مفعّل على `signals` و `news` و `comments`.

## النشر خطوة بخطوة

1. **Supabase**: أنشئ مشروعاً، ثم نفّذ ملفات `supabase/migrations/` بالترتيب في SQL Editor (أو `supabase db push`). اختيارياً نفّذ `seed.sql`.
   - Authentication → URL Configuration: ضع رابط موقعك في **Site URL**، وأضف `https://<موقعك>/auth/callback` إلى **Redirect URLs**.
   - بريد Supabase المدمج محدود بعدد قليل من الرسائل في الساعة؛ للإنتاج اربط SMTP مجاني (مثل Resend أو Brevo) من Authentication → SMTP Settings.
   - لجعل حسابك مديراً بعد أول دخول للموقع (مرة واحدة فقط، بعدها تدير الفريق من اللوحة):
     ```sql
     update profiles set role = 'admin' where id = (select id from auth.users where email = 'you@example.com');
     ```
2. **تيليجرام**: أنشئ بوتاً عبر @BotFather، أنشئ قناة وأضف البوت **مشرفاً** فيها. أرسل `/id` للبوت لمعرفة معرّفك ووضعه في `TELEGRAM_ADMIN_IDS`.
3. **البوت على Render**: New → Blueprint → هذا المستودع (يقرأ `render.yaml`)، واملأ المتغيرات. على Koyeb استخدم `apps/bot/Dockerfile` (البناء من جذر المستودع).
   ثم سجّل الـ Webhook مرة واحدة (مع ضبط المتغيرات محلياً):
   ```bash
   npm run set-webhook -w @qfx/bot
   ```
4. **الموقع على Vercel**: Import → Root Directory = `apps/web`، وأضف متغيرات `apps/web/.env.example`. `BOT_API_KEY` يجب أن يطابق قيمته في خدمة البوت.
5. **دورة المهام**: في [cron-job.org](https://cron-job.org) (مجاني) أنشئ مهمة كل 5 دقائق: `POST https://<bot>/api/jobs/tick` مع ترويسة `Authorization: Bearer <BOT_API_KEY>`. كاحتياط، الـ workflow في `.github/workflows/bot-tick.yml` يفعل نفس الشيء كل 10 دقائق بعد إضافة أسرار GitHub `BOT_PUBLIC_URL` و `BOT_API_KEY`. هذا أيضاً يمنع الخدمة المجانية من النوم.
6. **اللوحة**: ادخل `/admin` بحسابك المدير، أضف أماكن النشر من «الإعدادات» واضغط «فحص الصلاحيات»، ثم «فحص المصادر».
7. **أسعار حقيقية** (اختياري): مفتاح مجاني من twelvedata.com في `TWELVEDATA_API_KEY` للموقع (الشارت) وللبوت (تنبيهات الأسعار ونتيجة الاستطلاع) — 800 طلب/يوم.
8. **TradingView**: في التنبيه ضع الرابط `https://<bot>/webhooks/tradingview?secret=<TRADINGVIEW_WEBHOOK_SECRET>` ورسالة مثل:
   ```json
   {"symbol":"{{ticker}}","direction":"BUY","entry":{{close}},"sl":2340,"tp":2360}
   ```

## ملاحظات

- خدمة Render المجانية تنام بعد 15 دقيقة؛ أول طلب Webhook يوقظها (قد يتأخر ~30-50 ثانية). تيليجرام يعيد المحاولة تلقائياً.
- ترجمة المفكرة تعتمد على قاموس مصطلحات مجاني (مع إبقاء العنوان الإنجليزي عند عدم التطابق). الترجمة بالذكاء الاصطناعي ممكنة لاحقاً لكنها مدفوعة، لذلك لم تُفعَّل للحفاظ على تكلفة $0.

> ⚠️ تداول العملات بالهامش عالي المخاطر. المحتوى تعليمي وليس نصيحة استثمارية.
